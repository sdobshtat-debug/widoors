# Wide Doors (Fabric 1.21.11)

Великі двері 3 блоки завширшки і 3 заввишки, дві стулки, відкриваються.

- Wide Oak Door: відкривається ПКМ і редстоуном.
- Wide Iron Door: тільки редстоун.
- Крафт (обидва): PPP / PDP / PDP, де P = дубові дошки (або залізні злитки), D = дубові (або залізні) двері.
- Ставиться так: блок, у який ви ставите, стає НИЖНІМ СЕРЕДНІМ. Двері розкладаються вліво і вправо
  від нього відносно напрямку вашого погляду, тож у несиметричній стіні просто виберіть потрібний блок.
- Ламається ціле, випадає один предмет.

## Збірка
1. Найпростіше: на https://fabricmc.net/develop/template згенеруйте шаблон (1.21.11, Yarn, Java 21),
   розпакуйте і скопіюйте з цього архіву папку `src/` (замініть) та `gradle.properties`/`build.gradle`.
   Так ви отримаєте gradle wrapper (gradlew).
2. У папці проєкту: `./gradlew build` (Windows: `gradlew.bat build`).
3. Готовий мод: `build/libs/widedoors-1.0.0.jar` у папку mods. Потрібен Fabric API.
4. Для тесту: `./gradlew runClient`.

Якщо Gradle скаже, що якоїсь версії не існує, виправте її у gradle.properties за https://fabricmc.net/develop
